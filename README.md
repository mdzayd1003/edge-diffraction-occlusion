# 06 — Parameter Study of Sound Occlusion via Edge Diffraction

**[▶ Live demo](https://mdzayd1003.github.io/edge-diffraction-occlusion/)** — interactive results viewer, runs entirely in the browser.

How much does a barrier actually block? A wedge-diffraction model, a 126-point
parameter study, and an analysis that compares the predictions against listener
ratings.

Two implementations of the same physics — MATLAB (Octave-compatible) and Python —
that are tested against each other.

```
cd python && python -m pytest -q            # 82 tests, ~4 s
cd python && make quick                     # spectrum + full study + validation
cd matlab/tests && octave --no-gui --quiet --eval "exit(run_tests())"   # 12 tests
```

## What is implemented, and what is not

The model is the **Uniform Theory of Diffraction** wedge solution (Kouyoumjian &
Pathak): the diffracted field from a rigid wedge of exterior angle *n*π, with the
UTD transition function that keeps the field finite and continuous across the
shadow and reflection boundaries.

This is first-order diffraction over a single edge. It is not the
Biot-Tolstoy-Medwin secondary-source integral, and it does not model double
diffraction over the two edges of a thick barrier — which is the main reason a
real thick wall outperforms what this predicts for a fat wedge.

The time-domain response at 48 kHz comes from an inverse FFT of the transfer
function rather than from a time-domain edge integral. Below 20 Hz the
coefficient's 1/√k factor diverges, so that band is rolled off rather than
evaluated: the theory has nothing to say there.

## Why you can believe the implementation

Four checks, each a test in both ports:

**Half the field at the shadow boundary.** With the receiver exactly on the line
from the source over the edge, the total field must be exactly half the free
field — the diffracted term steps in to cover the discontinuity as the direct
sound switches off. Nothing is fitted to make this happen; it falls out of the
transition function. Measured: 0.50 ± 0.03 from 1 kHz up.

**Continuity across that boundary.** Moving the receiver through the boundary
must produce no step. The geometrical-optics diffraction coefficient fails this;
the uniform one is the fix, and the test pins it.

**Agreement with Maekawa.** Maekawa's chart is empirical — it comes from
measurements, not from this theory — so agreement is evidence rather than
circularity. UTD sits 1.4–1.7 dB above it across 7 octaves, which is the known
systematic offset, and the test allows 2 dB in either direction.

**Reciprocity.** Swapping source and receiver must change nothing. It holds to
machine precision, and it did not at first: taking the angular separation modulo
2π made the shadow test asymmetric, which quietly broke everything built on it.
That is now the thing the test checks by name.

## The two ports agree

`data/matlab_reference_study.csv` is the full 126-configuration study run through
the MATLAB port. A Python test compares every one of the 126 × 24 band values
against it and fails above 0.05 dB. The current largest disagreement is
**0.002 dB**.

That test is the point of having two ports. Without it, the second
implementation is a liability — it drifts, and nobody notices.

## The parameter study

7 barrier heights × 6 receiver distances × 3 wedge angles = 126 configurations,
each giving insertion loss in 24 third-octave bands from 50 Hz to 10 kHz, plus
an A-weighted single figure.

Fully crossed rather than one-at-a-time, so the marginal mean at each level of a
factor is directly comparable across factors. From `results/smoke/study.md`, at
500 Hz:

| Factor | Range across its levels |
|---|---|
| Barrier height (2–6 m) | 8.4 → 19.4 dB |
| Receiver distance (5–80 m) | 15.4 → 13.9 dB |
| Wedge angle (270° → thin screen) | 12.8 → 15.7 dB |

Height dominates, distance barely matters, and a **fatter wedge attenuates
less** — smaller open angle, larger diffraction coefficient, more energy into the
shadow. That is correct single-edge behaviour and is *not* what a real thick
barrier does, because a real one gets a second diffraction the model does not
include.

Band energy is integrated across each band on a log-frequency axis rather than
sampled at the centre. Diffraction is smooth in frequency, so it rarely matters
— except near a shadow boundary, where it does, and integrating is free.

## The listening test

**The ratings shipped here are simulated.** `data/listening_test.csv` was
generated by `diffraction.listening.simulate_ratings`; its provenance sidecar
records that, the report says so, and a test asserts the report says so. Replace
the CSV (and its sidecar) with a real study and nothing else changes.

The analysis itself is what a real study would need, and three of its choices are
the point:

- **Ratings are z-scored within participant.** One person lives in 3–5 of a 1–7
  scale, another swings the whole range. That is individual scale use, not
  disagreement about the stimuli. The raw correlation is reported alongside so
  the effect of normalising is visible.
- **Spearman, not Pearson.** The model predicts dB; the listener gives an
  ordinal rating. Only the ordering is comparable — assuming the rating scale is
  linear in dB would be assuming the answer. There is a test showing Pearson
  gives the wrong answer on a monotone-but-curved relationship.
- **The bootstrap resamples participants, not ratings.** Ten people is the
  sample size. Resampling the 120 individual ratings would treat them as 120
  independent observations and give an interval several times too narrow.

## Limits

- First-order, single-edge diffraction. No double diffraction over a thick
  barrier, no ground reflection, no atmospheric absorption, no finite barrier
  length. Each of those matters in a real prediction.
- Rigid faces. A porous or absorbing barrier needs the soft-boundary terms.
- The wedge is infinite along its edge. Real barriers end, and the field creeping
  around the ends sets a practical ceiling on insertion loss that this model does
  not see — which is why predicted losses above ~25 dB should be read as "as much
  as the barrier can give", not as a number.
- The listening-test ratings are simulated. The correlation demonstrates the
  analysis, not the model.
